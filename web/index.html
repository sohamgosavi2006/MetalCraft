Platform Architecture Documentation

Distributed Agentic Media Production Architecture Reference

1. Cloud Control Plane & iOS Division of Responsibilities

Cloud (Render): Intelligence, Gemini reasoning, Parallel research context, state machine, Grafana telemetry forwarder, and REST/WebSocket API.

iOS Engine (iPhone): Apple Metal GPU compute, AVFoundation multi-scene composition, local photo/video access, Camera Roll export, and persistent VideoArtifact storage.

2. REST API Endpoints (/api/v1)

  • GET /api/v1/health: Server and provider diagnostic health check.
  • POST /api/v1/agent/create: Gemini Creative Director plan synthesis.
  • POST /api/v1/generations: Dispatch generation job to iOS device.
  • GET /api/v1/generations: List recent generation jobs.
  • POST /api/v1/ios/register: Register iOS device session with capabilities.
  • GET /api/v1/audit: Retrieve audit logs.
  • GET /api/v1/analytics: Retrieve GPU performance metrics.
  • WS /ws/ios & WS /ws/web: Real-time WebSocket command & progress channels.
