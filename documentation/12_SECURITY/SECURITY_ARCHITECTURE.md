# Security Architecture

## Credential Management

| Credential | Storage | Access |
|-----------|---------|--------|
| Gemini API Key | Google Cloud Secret Manager | Server-side agent only |
| Grafana API Key | Google Cloud Secret Manager | Server-side agent only |
| Parallel API Key | Google Cloud Secret Manager | Server-side agent only |
| Cloud Run service account | Google Cloud IAM | Cloud Run service only |
| iOS auth token | Short-lived, generated by Cloud Run | iOS app (per-session) |

**RULE**: No API keys in iOS source code, Info.plist, or public repository.

## API Authentication

```
iOS App
    │
    │ HTTPS POST (Bearer token)
    │
    ▼
Cloud Run (validates token)
    │
    │ Accesses Secret Manager
    │
    ▼
Gemini / Grafana / Parallel
```

## Input Validation

1. **EditPlan validation**: All incoming EditPlans are validated against the JSON schema before execution
2. **Operation type whitelist**: Only known ProcessingOperation types are accepted
3. **Parameter range validation**: All numeric parameters bounded (e.g., sigma 0.1-50.0)
4. **Array length limits**: Maximum 20 operations per EditPlan
5. **String sanitization**: User prompts sanitized before passing to Gemini/Parallel

## Prompt Injection Protection

1. System prompt and user prompt are strictly separated
2. User input is treated as data, never as instructions
3. EditPlan outputs are validated against schema (not executed as code)
4. Tool outputs are bounded and typed (no arbitrary code execution)

## Media Privacy

| Data | Policy |
|------|--------|
| Original images/videos | LOCAL ONLY — never leaves device |
| Processed results | LOCAL ONLY |
| Media metadata (resolution, FPS) | Sent to cloud with request |
| Low-res thumbnail (<100KB) | Sent to cloud only with user consent |
| Histogram summary | Sent to cloud (no visual content) |
| Processing telemetry | Sent to Grafana (timing data only, no media) |

## IAM Configuration

- Cloud Run service account: `metalcraft-agent@project.iam.gserviceaccount.com`
- Permissions: Secret Manager accessor, Vertex AI user
- Principle of least privilege applied
